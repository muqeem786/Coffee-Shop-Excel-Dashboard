# Coffee Shop Excel Dashboard

## Project Overview

This project presents an interactive Coffee Shop Sales Dashboard developed in Microsoft Excel to analyze sales performance, customer footfall, product demand, order patterns, and store-level performance. The dashboard provides actionable business insights through dynamic visualizations, KPI tracking, and interactive filters.

## Key Metrics

- Total Sales: $698,812.33
- Total Footfall: 149,116
- Average Bill per Person: 4.69
- Average Orders per Person: 1.44

## Features

- Sales Performance Analysis
- Customer Footfall Tracking
- Hourly Order Trend Analysis
- Product Category Distribution
- Order Size Distribution
- Store Location Performance
- Top-Selling Products Analysis
- Weekday Order Analysis
- Interactive Slicers and Filters

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Dashboard Design

## Key Insights

- Customer orders peak during morning hours.
- Coffee products contribute the highest share of total sales.
- Regular and Large sizes account for most customer orders.
- Hell's Kitchen and Astoria stores generate the highest sales.
- Barista Espresso is the top-selling product.
- Weekday sales are generally higher than weekend sales.
